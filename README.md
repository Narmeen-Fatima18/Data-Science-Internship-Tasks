## Overview

## Task 1: Iris Dataset Analysis

**Objective:** Explore and visualize the dataset

**Approach:**

* Data loading using pandas
* Data visualization using seaborn and matplotlib
* Logistic Regression model

**Result:**

* Achieved high classification accuracy
* Petal features are strong indicators

---

## Task 2: Credit Risk Prediction

**Objective:** Predict loan approval

**Approach:**

* Missing value handling
* Feature encoding
* Logistic Regression

**Result:**

* Good accuracy
* Credit history is the most important feature

---

## Task 3: Customer Churn Prediction

**Objective:** Identify customers likely to leave

**Approach:**

* Data preprocessing
* Decision Tree model
* Feature importance analysis

**Result:**

* Age, balance, and geography are key factors

---

## Task 4: Insurance Cost Prediction

**Objective:** Predict medical charges

**Approach:**

* Linear Regression
* Correlation analysis

**Result:**

* Smoking has the highest impact on charges

---

## Task 5: Loan Acceptance Prediction

**Objective:** Predict which customers accept loan

**Approach:**

* Data exploration
* Logistic Regression

**Result:**

* Balance, job, and age influence decisions
